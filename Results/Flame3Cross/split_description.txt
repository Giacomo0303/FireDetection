1. PROTOCOLLO SPERIMENTALE E CONVENZIONE ETICHETTE
--------------------------------------------------
- Protocollo: Leave-One-Dataset-Out (Zero-Shot Cross-Dataset Evaluation).
  Il modello viene addestrato e validato esclusivamente su 3 dataset (FLAME2,
  FireMan-UAV-RGBT, RGBT-3M) e valutato sul Test Set costituito al 100% da FLAME3
  (completamente assente sia dal Training Set che dal Validation Set).
- Convenzione classi:
  * 1.0 (Fire)   : Presenza di incendio attivo (fiamma e/o fumo da incendio).
  * 0.0 (No_Fire): Assenza totale di incendio (né fiamma né fumo).

2. REGOLE DI COSTRUZIONE PER SINGOLO DATASET
--------------------------------------------

A) FLAME2 (Data/FLAME2) -> Diviso solo tra Train e Val (0 immagini in Test)
   - Classe No_Fire (0.0) [Intervallo 0: frame 1 - 13.700]:
     * Val   : range(1, 1801, step=12)     -> 150 immagini
     * Buffer: frame 1801 - 2300 (500 frame scartati per evitare data leakage)
     * Train : range(2301, 13701, step=13) -> 877 immagini
               (include la sequenza finale 12.500 - 13.700 con orizzonte, cielo e nuvole)
   - Classe Fire (1.0) [Intervalli 1..18: frame 13.701 - 53.451]:
     * Train : Intervalli 1..15 (frame 13.701 - 45.279), campionati per ciascun
               intervallo con range(start, end + 1, step=36) -> 884 immagini
     * Buffer: frame 45.280 - 45.779 (primi 500 frame dell'intervallo 16 scartati)
     * Val   : Intervalli 16..18 dal frame 45.780 fino a 53.451, campionati con
               range(max(start, 45780), end + 1, step=48)    -> 162 immagini

B) FireMan-UAV-RGBT (Data/FireMan-UAV-RGBT/Binary/Multimodal/rgbt) -> Solo Train e Val
   - Train: unisce le cartelle ufficiali "train" e "test" di FireMan:
     * Fire   : dji_video_007..012 con passo [::4] (600) + dji_video_001..002 con passo [::3] (170)
                -> 770 immagini
     * No_Fire: dji_video_013..014 con passo [::1] (139) + dji_video_003 con passo [::1] (11)
                -> 150 immagini
   - Val  : cartella ufficiale "val" di FireMan:
     * Fire   : dji_video_004..005 con passo [::2] -> 80 immagini
     * No_Fire: dji_video_006 con passo [::1]      -> 11 immagini

C) RGBT-3M (Data/RGBT-3M) -> Solo Train e Val
   - Tutti i frame sono etichettati come 1.0 (Fire).
   - Ordinati alfabeticamente per basename e sottocampionati:
     * Train (video1, video2, video3, video4, video8, video9, video10): [::14] -> 684 immagini
     * Val   (video5)                                                 : [::15] -> 111 immagini

D) FLAME3 (Data/FLAME3) -> 100% nel Test Set (Unseen Dataset)
   - Sottocartelle usate: "RGB/Corrected FOV" e "Thermal/Raw JPG".
   - Tutte le immagini vanno esclusivamente nel Test Set senza sottocampionamento:
     * Test Fire   : 622 immagini
     * Test No_Fire: 116 immagini
     * Totale Test : 738 immagini

3. SHUFFLE E SALVATAGGIO
------------------------
- train_set.csv viene mescolato con random.seed(42) e random.shuffle(train_set).
- val_set.csv e test_set.csv non vengono mescolati.
