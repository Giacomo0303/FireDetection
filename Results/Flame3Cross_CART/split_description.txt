1. PROTOCOLLO SPERIMENTALE E OBIETTIVO
--------------------------------------
- Protocollo: Leave-One-Dataset-Out (Zero-Shot Cross-Dataset Evaluation) con
  arricchimento di campioni negativi naturali da UAV (dataset CART - Caltech Aerial RGBT).
- Obiettivo dell'esperimento:
  Verificare se l'integrazione di campioni negativi aerei ad alta variabilità (rocce
  scaldati dal sole, fitta vegetazione e riflessi d'acqua da drone) nel Training Set
  migliora la specificità e riduce i falsi allarmi sul Test Set non visto FLAME3
  (100% unseen sia in Train che in Val) e su scenari reali di terra (MyData).
- Convenzione etichette:
  * 1.0 (Fire)   : Presenza di incendio attivo (fiamma e/o fumo da incendio).
  * 0.0 (No_Fire): Assenza totale di incendio.

2. REGOLE DI COSTRUZIONE PER SINGOLO DATASET
--------------------------------------------

A) FLAME2 (Data/FLAME2) -> Diviso tra Train e Val (0 immagini in Test)
   - Classe No_Fire (0.0) [Intervallo 0: frame 1 - 13.700]:
     * Val   : range(1, 1801, step=12)     -> 150 immagini
     * Buffer: frame 1801 - 2300 (500 frame scartati per data leakage)
     * Train : range(2301, 13701, step=13) -> 877 immagini
               (include sequenza 12.500 - 13.700 con cielo, orizzonte e nuvole)
   - Classe Fire (1.0) [Intervalli 1..18: frame 13.701 - 53.451]:
     * Train : Intervalli 1..15, step=36   -> 884 immagini
     * Buffer: frame 45.280 - 45.779 (500 frame scartati)
     * Val   : Intervalli 16..18, step=48  -> 162 immagini

B) FireMan-UAV-RGBT (Data/FireMan-UAV-RGBT/Binary/Multimodal/rgbt) -> Train e Val
   - Train: unione delle cartelle "train" e "test" ufficiali di FireMan:
     * Fire   : dji_video_007..012 [::4] (600) + dji_video_001..002 [::3] (170) -> 770 immagini
     * No_Fire: dji_video_013..014 [::1] (139) + dji_video_003 [::1] (11)       -> 150 immagini
   - Val  : cartella "val" ufficiale:
     * Fire   : dji_video_004..005 [::2] -> 80 immagini
     * No_Fire: dji_video_006 [::1]      -> 11 immagini

C) RGBT-3M (Data/RGBT-3M) -> Train e Val (Solo Fire = 1.0)
   - Train (video1, video2, video3, video4, video8, video9, video10) [::14] -> 684 immagini
   - Val   (video5)                                                 [::15] -> 111 immagini

D) CART (Data/labeled_rgbt_pairs) -> 100% nel Training Set (Tutte No_Fire = 0.0)
   - 504 coppie estratte con campionamento bilanciato da 2.282 coppie aerial RGB-T:
     * Foresta montana (big_bear, caltech-nature) [::3]   : 165 immagini
     * Canyon rocciosi e sabbia (ColoradoRiver)   [::2]   : 180 immagini
     * Laghi, acqua e riflessi (Castaic_Lake, duck) [::9] : 159 immagini
   - Canali: RGB da color/, Termico da thermal8/ (_eo- -> _thermal-)

E) FLAME3 (Data/FLAME3) -> 100% nel Test Set (Unseen Dataset)
   - Sottocartelle "RGB/Corrected FOV" e "Thermal/Raw JPG":
     * Test Fire   : 622 immagini
     * Test No_Fire: 116 immagini
     * Totale Test : 738 immagini
